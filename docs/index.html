MULTI-LAYERED ENDPOINT DEFENSE

7 Integrated Security Engines

Every uploaded binary, file-system event, and outbound socket connection is inspected across seven specialized defense modules.

MODULE 01

Industry-Grade Static PE Analyzer

Inspects Windows Executables without execution, extracting 19 ML-ready features in a single pass with BLAKE3 hashing (~14× faster) plus SHA-256, SHA-1, and MD5.

  • 60+ Suspicious APIs: Crypto (BCryptEncrypt), File Enum, Process Injection (WriteProcessMemory), Anti-Debug, Lateral Movement, & Shadow Copy deletion (vssadmin).
  • Packer & Anomaly Checks: Detects .upx, .aspack, .themida, Authenticode signatures, TLS callbacks, and section entropy.
MODULE 02

Thread-Safe YARA Scanner Engine

High-throughput signature matching built for concurrent Celery worker execution with automated rule hot-reloading.

  • Thread-Safe Caching: Uses threading.Lock with individual file mtime cache invalidation across .yar and .yara rules.
  • Forensic Match Extraction & ReDoS Guard: Extracts first 5 matched strings (× 64 bytes) with strict regex timeouts.
MODULE 03

Ensemble ML Classifier (19 Features)

Soft-voting ensemble combining GradientBoosting + RandomForest trained on 15,550 samples across ransomware, trojans, droppers, worms, and packed malware.

  • Validated Accuracy: Stratified 5-fold cross-validation achieving 99.96% precision and < 0.1% false negative rate.
  • Heuristic Fallback: Multi-signal weighted heuristic guarantees uninterrupted scoring even before model training.
MODULE 04

Generative AI Threat Explainer

Translates dense PE headers, YARA hits, and network telemetry into plain-English incident response playbooks via Groq (LLaMA 3.1) & LangChain.

  • Rich Markdown SOC UI: Renders syntax-highlighted remediation commands, tables, and copy buttons in real time.
  • Conversational Analyst: Interactive security chat assistant plus automated PDF executive report narratives.
MODULE 05

Honeyfile Trap & Process Attribution

Active zero-day ransomware tripwire deploying realistic, non-trivial decoy files (passwords.txt, bitcoin_wallet.dat, tax_returns_2025.pdf).

  • PID & Entropy Forensics: Pinpoints offending process name/path via psutil and flags entropy jumps > 7.0.
  • Instant WebSocket Alerts: Broadcasts CRITICAL alerts over Django Channels with a 10s anti-flood cooldown.
MODULE 06

Live Network Monitor & Threat Intel

Real-time socket telemetry enriched with Emerging Threats IP feeds, MaxMind GeoLite2 country resolution, and ARP Spoofing MitM detection.

  • C2 & Beaconing Detection: Flags C2/mining ports (4444, 8443, 9001, 3333) and detects periodic callbacks via coefficient of variation.
  • 0–100 Connection Risk Score: Maps every socket to its owning PID, executable path, and user account.
MODULE 07 • ORCHESTRATOR CLEAN → LOW → MEDIUM → HIGH → CRITICAL

Normalized Scan Pipeline & Zero-Overwrite Security

Orchestrates VirusTotal (30%), YARA (25%), Ensemble ML (25%), and Static PE Analysis (20%) with an independent +20% ransomware indicator boost. Enforces magic-byte file verification (never trusting extensions), Celery task timeouts (5m hard / 4m soft), and zero-overwrite secure file deletion post-analysis.

LOCAL DEPLOYMENT

Quickstart Installation

Requires Python 3.10+, Node.js v18+, Redis (`localhost:6379`), and API keys for VirusTotal & Groq.

bash — Backend & ML Model Training 
git clone https://github.com/rudra00434/Ransomware_Shield.git
cd Ransomware_Shield/backend

# Create & activate virtual environment
python -m venv venv
# Windows: venv\Scripts\activate | Mac/Linux: source venv/bin/activate

pip install -r requirements.txt
# Add GROQ_API_KEY & VT_API_KEY to .env

python manage.py migrate
python -m ai_engine.ml.train_model
python manage.py runserver
bash — Background Workers (Separate Terminals) 
# Terminal 2: Ensure Redis Server is running on localhost:6379
redis-server

# Terminal 3: Start Celery Scan Worker (use --pool=solo on Windows)
cd backend && venv\Scripts\activate
celery -A config worker -l info --pool=solo

# Terminal 4: Arm Honeyfile Ransomware Trap
cd backend && venv\Scripts\activate
python manage.py run_honeyfile
bash — Vite Client & Optional MaxMind GeoIP 
# Terminal 5: Start React + Vite Frontend
cd frontend
npm install
npm run dev
# Open http://localhost:5173 in your browser

# Optional GeoIP Country Resolution:
# Download GeoLite2-Country.mmdb from MaxMind
# Place inside: backend/geoip/GeoLite2-Country.mmdb
